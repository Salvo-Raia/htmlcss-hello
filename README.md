## 📝 Assignment

The goal of this exercise is to become familiar with Git and GitHub by creating a basic HTML project and managing its version control.

### Requirements

* Create a folder for the new project.
* Open the project folder in Visual Studio Code.
* Create a basic HTML file.
* Initialize a Git repository and make the first commit.
* Push the repository to GitHub for the first time.
* Continue developing the proposed layout incrementally, making regular commits.
